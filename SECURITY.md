# Security policy

## Supported versions

Only the latest published version of the `Datapoint.Mediator` packages receives security fixes. Versions `3.0.0` and earlier are not supported.

## Reporting a vulnerability

Please **do not report security vulnerabilities in public issues, discussions or pull requests.**

Report them privately through GitHub instead: open the repository's [Security tab](https://github.com/datapoint-software/mediator/security) and choose **Report a vulnerability**, or go directly to [the private report form](https://github.com/datapoint-software/mediator/security/advisories/new).

Include as much of the following as you can:

- the affected package and version;
- a description of the vulnerability and its impact;
- the steps or code needed to reproduce it.

We'll investigate, keep you informed through the report, and credit you in the advisory once a fix is published, unless you prefer to stay anonymous.
